Welcome to Git & Github

What is Git

Git is a free, open-source distributed version control system designed to handle everything from small to very large projects with speed and efficiency.

  • Version Tracking: It records every change made to a file, allowing developers to "time travel"
    back to any previous state of the project.
  • Local Management: Git runs locally on a developer's computer.
    You don't need an internet connection to track your changes or create new versions.
  • Branching & Merging: It allows developers to create "branches"
    to work on new features safely without affecting the main code. Once the feature is ready, it can be merged back.
  • Data Integrity: Every change is cryptographically hashed, ensuring that the code history
    cannot be altered or corrupted without notice.

What is Github

GitHub is a cloud-based hosting service that lets you manage Git repositories. It provides a web-based interface and additional tools for team collaboration.

  • Cloud Hosting: It provides a remote location on the internet
    where teams can store their Git repositories, making code accessible from anywhere.
  • Collaboration Tools: It introduces features like "Pull Requests" and "Code Reviews"
    where team members can discuss changes, suggest improvements, and approve code before it is merged.
  • Project Management: GitHub includes non-coding tools such as "Issue Tracking"
    "Project Boards," and "Wikis" to help teams organize their tasks and documentation.
  • Social Coding: It acts as a social network for developers, allowing them to follow projects,
    contribute to open-source software, and showcase their work (portfolios) to potential employers.
